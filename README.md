# Maruti Suzuki Financial Model

A complete 10-year financial model (2016–2025) for *Maruti Suzuki Ltd.* built in Microsoft Excel.

## 📊 Project Overview
This model includes:
- Income Statement, Balance Sheet, and Cash Flow projections  
- Ratio Analysis (Profitability, Liquidity, Efficiency)  
- DuPont and Altman Z-Score Analysis  
- Sales, EBITDA, and EPS Forecasting using historical trends  

## 🧰 Tools Used
- Microsoft Excel  
- Financial Modelling Techniques  
- Data Visualization (Charts & Forecast Graphs)

## 🎯 Key Insights
- Demonstrates Maruti Suzuki’s financial recovery post-2020 slowdown  
- Forecasted steady growth in sales and profitability through 2025  
- Financially stable company with strong Altman Z-Score
